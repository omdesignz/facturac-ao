## Verified boundaries and accepted behavior

- Explicit public workspace/entity/environment paths are mandatory. No request uses mutable browser workspace state. Foreign/sibling documents and wrong environments remain invisible. Newly tested active membership in a second workspace permits only that explicit context without changing browser selection. Unresolved environment is not accepted as an API environment.
- All five active human membership roles retain the signed read permission. Direct capability calls revalidate membership and current actor verification/MFA; tests revoke these after context creation. Workspace-level membership, rather than invented entity-specific grants, is the signed existing model. Read-only support impersonation is permitted and attributed; consequential capabilities remain blocked.
- The serializer exposes exactly ten approved document/status fields. No customer PII, internal IDs, signing material, raw submission payloads or credentials are loaded into the response. Projection filters and serialization use the same authority. Reads do not rewrite persisted/frozen fiscal status. `received` is not validation; processing `cancelled` is not fiscal cancellation; legacy provenance is not a fresh AGT confirmation.
- List pages are bounded to 50, page to 10,000, with descending ID order and whitelisted scalar filters. Unknown/authority-shaped filters fail. A 1-versus-50-document test proves constant query count. Exact counts and deep offsets can become expensive at production scale; measure scoped query plans before broader exposure. This is not a proven unbounded-fetch or cross-tenant defect.
- Audit metadata contains server correlation, approved actor/scope/version and bounded pagination counts, not arbitrary request filters or returned fiscal payloads. Pre-resolution denials intentionally omit unvalidated tenant scope. Authentication failures and invalid syntax are not falsely labelled executed document reads. Correlation is diagnostic, never authority.
- GET/HEAD are the only operations. No AGT HTTP, notifications, issuance or delivery occurs. Session middleware and existing throttling remain in use. Error normalization preserves safe protocol headers and session cookies. No external authentication product is implied by this session adapter.
